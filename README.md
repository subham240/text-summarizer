# 🤖 AI Text Summarizer

An AI-powered text summarization web application built using a fine-tuned T5 Transformer model.

## 🛠️ Technologies

- Python
- PyTorch
- Hugging Face Transformers
- T5
- FastAPI
- HTML
- CSS
- JavaScript

## ✨ Features

- Summarizes long text and conversations
- Fine-tuned T5 Transformer model
- FastAPI backend
- Simple and modern web interface
- Text preprocessing and cleaning

## 📂 Files

- `app.py` — FastAPI backend and summarization logic
- `index.html` — Web interface
- `README.md` — Project documentation
